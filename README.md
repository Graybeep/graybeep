## About

I am an aspiring **Data Scientist** focused on the practical side of machine learning: taking a problem from raw, unstructured data through to a trained, evaluated, and reproducible model.

- **Building end-to-end ML pipelines** — ingestion, cleaning, feature engineering, training, evaluation, and iteration, structured so a result can be reproduced rather than rediscovered.
- **Working hands-on with data** — wrangling messy datasets with `pandas` and `NumPy`, handling missing values and outliers, and validating assumptions with statistical tests before a model is ever fit.
- **Training and tuning models** — supervised learning with `scikit-learn`, cross-validation, hyperparameter search, and honest evaluation against the metrics that actually matter for the problem.
- **Communicating results** — exploratory analysis and visual reporting with `Matplotlib` and `Seaborn`, because an unexplained model is an unused model.
- **Foundations in systems programming** — C and C++ alongside Python, which keeps performance and memory behaviour in view when data volume grows.
- **Currently deepening** — deep learning frameworks, feature stores, and the tooling that moves a model from a notebook into something maintainable.

Open to collaboration on AI/ML projects, internships, and data-driven research.
